# Credenciais Necessárias para os Serviços Instalados

Este documento lista todas as contas, credenciais e tokens recomendados para utilizar plenamente os aplicativos instalados via WinGet.

## Checklist Rápido (O que pode ser automatizado)
- [ ] GitHub + SSH + PAT
- [ ] OpenRouter (chaves)
- [ ] Cloud Provider Tokens (AWS, Azure, GCP, etc)
- [ ] Beekeeper Studio (conexões)
- [ ] Docker Hub
- [ ] KeePassXC credential retrieval
- [ ] Postman (sincronização de coleções e workspaces)
- [ ] Obsidian Account (download do Git de Notas)
